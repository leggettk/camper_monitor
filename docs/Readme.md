# Camper Monitor

An ESP32-based LTE camper monitoring system.

## Hardware

- LILYGO T-SIM7000G (ESP32-WROVER-B)
- SIM7000G LTE modem
- SSD1306 OLED display
- DS18B20 temperature sensors

## Features

- Ambient, refrigerator, freezer, and outside temperature
- MQTT to Home Assistant
- SMS backup alerts
- Shore power monitoring
- Battery voltage monitoring
- GPS (planned)
